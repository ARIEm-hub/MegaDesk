# MegaDesk Mobile v3

Исправление запуска приложения.

Главное изменение:
- УБРАН `intent://...package=com.bitrix24.android`
- УБРАН любой Google Play fallback
- Кнопка теперь обычная прямая ссылка:
  `bitrix24://`

Это соответствует документации Bitrix24: `bitrix24://` может вывести мобильное приложение
на передний план, но не умеет открыть конкретную внутреннюю страницу MegaDesk.

Поэтому после запуска пользователь вручную:
Меню -> Маркет -> MegaDesk -> Создать заявку

Также мобильная верстка теперь является основной.
Десктопная двухколоночная версия включается только при ширине >= 900px.
