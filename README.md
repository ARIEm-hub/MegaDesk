# IT Отдел — Bitrix24 / MegaDesk

Адаптивный GitHub Pages сайт.

## Что изменено

- Полностью адаптирован под телефоны.
- На ширине до 780 px включается отдельная мобильная компоновка.
- Блоки идут вертикально, без десктопной двухколоночной сетки.
- Кнопка «Открыть Bitrix24» крупная и удобна для телефона.
- Инструкция:
  1. Открыть Bitrix24.
  2. Меню.
  3. Пролистать до «Маркет».
  4. Нажать MegaDesk.
  5. Создать заявку.

## Публикация GitHub Pages

1. Создайте репозиторий.
2. Загрузите `index.html` в корень.
3. Settings -> Pages.
4. Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Save.

QR-код делайте на итоговую ссылку GitHub Pages.
